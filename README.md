# Minecraft Recipe Explorer – Feedback

This repo is the public place for bug reports, feature requests and modpack requests for
[Minecraft Recipe Explorer](https://minecraft.strider820.me), a web app for browsing modpack items and recipes
(JEI-style) and planning raw materials, outside the game.

The app's source code is not in this repo; it only holds issues.

To get started, click **[New issue](https://github.com/strider820/minecraft-recipe-explorer-feedback/issues/new/choose)**
and pick a form: **Bug report**, **Feature request**, **Modpack request** or **Mod owner request**.
Each form asks for the details below.

## Reporting a bug
Open an issue and include:
- The page link (copy it from your address bar)
- The modpack and version
- What you expected and what happened instead
- A screenshot if it shows the problem
- Your browser and device, if it looks like a display issue

## Requesting a feature
Open an issue describing what you're trying to do and how the feature would help. Check existing issues
first and add a 👍 to ones you want rather than opening a duplicate.

## Requesting a modpack
Open an issue with the pack name, its CurseForge or Modrinth link, and the version you play.
👍 existing requests to vote for them.

## Mod authors
If you'd like to grant or decline permission for your mod's icons, or have your mod's icons or recipes
handled differently (or removed), open a **Mod owner request** or reach out on Discord: **@strider820**.
